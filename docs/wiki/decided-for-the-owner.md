# Decided for the owner

Design decisions the chief of staff or an agent made for the owner, under the owner's leave of 2026-11-15 to go ahead with decisions that are simple to reverse ([user-preferences](user-preferences.md)). The owner reads this page to go over them; each line says how to overrule. Hard-to-reverse decisions, anything that stores user data, and new design directions go to the owner first and never appear here (the chief of staff's interpretation).

An implementer whose brief marks a decision "decided for the owner" adds its line here in the same PR ([implementer brief](../agents/implementer-brief.md)): date, decision, issue and PR, how to overrule, and the owner's verdict once given.

- 2026-11-15, **"Pair again"**: a Phone that forgot the pairing gets Pair again in the Setup Window, which removes the stale pairing (the app's first use of BlueZ `RemoveDevice`) and pairs afresh. #377, PR #382 (`cd68b35`). To overrule: say so, and the window goes back to reading key-missing as "Phone calls off". **Owner: kept** (2026-11-15).
- 2026-11-15, **"Phone setup…" with a Phone set up opens on its finish page**, with Pair another phone, instead of on choosing a Phone. #389, PR #393 (open when written). To overrule: name the page it should open on.
- 2026-11-15, **the gallery captures short states from the harness only** (the chief of staff's call): it stops the app on the first frame that shows a short state, with no test hook added to the app. #384, PR #391 (`ef9e3a1`). To overrule: ask for the test-only feature (#391's "option A"), which reverses #248.
- 2026-11-15, **a refused Phone is asked again while it stays connected**: when a Phone refuses Contacts, or the person says no on its prompt, Desktop Calls asks again quietly, every 10 s for about 10 minutes after the Phone connects, then every 5 minutes, so Contacts turned on later are picked up without pairing again. A Phone that shows its prompt again when asked is asked no more until it reconnects. #394 and #392, PRs #401 (`92cd552`) and #408. To overrule: name another interval, or ask for no asking after a no on the prompt (a Phone that asked then needs a reconnect to pick up Contacts turned on later).
- 2026-11-16, **how the nightly run works** (the move to nightly is the owner's own decision; these details are the implementer's): it runs at 03:17 in UTC-5; the scorecard scores the scenario results CI's latest run on `main` kept rather than running the scenarios again; a red night goes to one rolling issue, "Nightly CI is red", commented on while it stays open; and a scheduled night after a red one runs again at the same commit, since it compares with the last green nightly. PR #430 ([testing](testing.md)). To overrule: name another hour, ask for the scenarios to run in the nightly itself (six more runners a night), or for an issue per red night.
- 2026-11-16, **a mellow default Ringer** (the chief of staff's call, from the research note on #432): the Desktop rings with a soft four-note chime the app synthesises itself (no bundled sound file, no licence question) in place of the sound theme's `phone-incoming-call`, at 60 % stream volume (about -22 LUFS as played, against -6.8 LUFS before), with a 2 s pause between repeats and the first repeat faded in. The ring stream is named "Desktop Calls ringer", has media role `Notification`, and WirePlumber neither restores nor saves its volume. The sound, volume and pause are one `RingerSettings` value, ready for a Ringer settings page; no page, config file or per-Contact sound yet. Hear it with `just ring`. #432, PR #434. To overrule: say what sounds wrong (pitch, notes, loudness, pause), or ask for the old sound back.
- 2026-11-16, **the copy pass's wording** (the pass is the owner's own request, "easy enough to read that you can tell what everything does at a glance"; each new wording is the implementer's): 84 strings shorter, none longer. PR #435 (open when written), whose body has the longer table, the facts dropped and the three the implementer is least sure of. **Supersedes** the earlier wording of these strings wherever [product-shape](product-shape.md) quotes it.
