- 2026-11-04: Known risks from that research: (1) there is no `Deactivate()`, so Handoff to the Phone needs a prototype; (2) Android sends Call audio to whichever hands-free device was activated most recently, so earbuds and the Desktop compete; (3) the API is young and has little field testing. Prior art: Foner (`AminBlg/kaller`, GPL-3.0) uses the same architecture.
